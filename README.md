# Danich_SSD130x_Fast (v2.0.0)
Лёгкая и сверхбыстрая библиотека **2-в-1** для монохромных OLED-дисплеев 128×64 на контроллерах **SSD1306** и **SSD1309** (I2C через `microWire`).

- **Два режима работы в одной библиотеке (выбор при создании объекта):**
  - **`Danich_SSD130x_Fast<>` (`OLED_NO_BUFFER`):** **0 байт ОЗУ** под кадр, прямой потоковый рендер в GDDRAM дисплея. Весь код буфера и векторной графики автоматически вырезается компилятором.
  - **`Danich_SSD130x_Fast<OLED_BUFFER>`:** **1024 байта ОЗУ**, попиксельная адресация `Y (0..63)`, наложение текста и фигур без затирания, наклонные линии, круги, закрашенные прямоугольники и **умный `update()`**, который отправляет по I2C только изменённый участок экрана.
- **Раздельные профили SSD1309 и SSD1306:** для SSD1309 отключён лишний внутренний DC-DC charge pump — меньше нагрев матрицы и шире диапазон контраста.
- **Совместимость со шрифтами `iarduino_OLED_txt`:** файл `DefaultFonts.h` оставлен без изменений — поддерживаются любые многостраничные шрифты (`SmallFontRus`, `MediumFontRus`, `BigFontRus`, `MegaFontRus` и пользовательские).
- **Масштабирование шрифтов (`1×`, `2×`, `4×`):** растягивание любого шрифта на лету — можно использовать один мелкий шрифт вместо нескольких тяжёлых для экономии Flash.
- **Пакетный потоковый рендер:** байты глифов читаются из `PROGMEM` и сразу уходят в `microWire` единой непрерывной транзакцией (поддерживается разгон шины `Wire.setClock(600000L)`).
- **Плавная попиксельная бегущая строка (`printTicker` / `printScroll`):** работает в произвольном окне экрана и не нагружает процессор в холостых циклах `loop()`.
- **Гибридная работа с кириллицей:** автоопределение **UTF-8** (`"Привет"`) и готовых восьмеричных кодов **CP866** (`"\223\241\245..."`) без ручного переключения режимов, плюс поддержка **Windows-1251**.

### Совместимость
* **AVR (Arduino Uno, Nano, Pro Mini, Mega):** работает поверх сверхлёгкой библиотеки `microWire` (0 лишних буферов).
* **ESP32 / ESP8266:** работает поверх встроенной `Wire` с поддержкой произвольных пинов `SDA, SCL` и автоматической пакетной отправкой.

## О проекте и преемственности
Библиотека создана как **симбиоз лучших решений [iarduino_OLED_txt](https://github.com) и [GyverOLED](https://github.com)** с глубокой оптимизацией рендера:
* **От `iarduino_OLED_txt`:** постраничная архитектура вывода, удобное API выравнивания (`OLED_L`, `OLED_C`, `OLED_R`, `OLED_T`, `OLED_B`), переменные курсора `numX` / `numY` и оригинальный файл шрифтов `DefaultFonts.h`.
* **От `GyverOLED`:** шаблонное переключение режимов (`OLED_NO_BUFFER` / `OLED_BUFFER`), скоростной потоковый транспорт поверх `microWire`, поддержка разгона шины I2C и концепция кратного масштабирования шрифта.
* **Уникальные доработки `Danich_SSD130x_Fast`:**
  * Пакетная отправка строк, битмапов и `clrScr()` в одну транзакцию `microWire` без промежуточных буферов нарезки по 30 байт.
  * Трекер «грязного прямоугольника» (`dirty rect`) в буферном режиме: `update()` пересылает по I2C только изменившуюся часть экрана.
  * Нативная поддержка строк из Flash (`F("...")`) во всех методах вывода.
  * Исправлено вертикальное центрирование `OLED_C` для высоких шрифтов, добавлено правильное округление `double`, сохранение знака минус для чисел `-0.xx` и защита от переполнения `uint32_t`.
  * Профили `OLED_1309` / `OLED_1306`, побитовое масштабирование многостраничных шрифтов, оконный скроллинг `printScroll`, автопилот `printTicker` / `resetTicker`, пунктирная графика и `printPadZero`.

## Установка
1. Установите зависимость — библиотеку **[microWire](https://github.com)** (от AlexGyver).
2. Скопируйте папку **`Danich_SSD130x_Fast`** (внутри должны быть `Danich_SSD130x_Fast.h`, `Danich_SSD130x_Fast.tpp` и `DefaultFonts.h`) в директорию *Документы/Arduino/libraries/*.
3. Перезапустите Arduino IDE.

## Инициализация
```cpp
#include <Danich_SSD130x_Fast.h> // На AVR автоматически подключит microWire.h, на ESP32 — Wire.h

// Вариант 1: Без буфера (0 байт ОЗУ — по умолчанию)
DanichOLED myOLED(0x3C);            // Короткий псевдоним (или Danich_SSD130x_Fast<> myOLED(0x3C);)

// Вариант 2: С видеобуфером (1024 байта ОЗУ — наклонные линии, круги, попиксельный Y)
// DanichOLED_Buf myOLED(0x3C);     // Короткий псевдоним (или Danich_SSD130x_Fast<OLED_BUFFER> myOLED(0x3C);)

void setup() {
  myOLED.begin(OLED_1309);          // Для экранов на SSD1309 (по умолчанию)
  // myOLED.begin(OLED_1306);       // Для экранов 0.96" / 1.3" на SSD1306 (включает DC-DC charge pump)
  // myOLED.begin(OLED_1309, 21, 22); // Для ESP32 / ESP8266 можно сразу указать пины SDA и SCL

  Wire.setClock(600000L);           // Разгон I2C до 600–800 кГц для максимального FPS
}
```

uint8_t getFontWidth();                   // Ширина символа в пикселях (с учётом масштаба)
uint8_t getFontHeight();                  // Высота символа (в страницах для NO_BUFFER, в пикселях для BUFFER)
void setPageCoord(bool usePages);         // Формат координат Y для текста: true = страницы (0..7), false = пиксели (0..63)

// Выравнивание col: OLED_L (лево), OLED_C (центр), OLED_R (право), OLED_N (текущий X)
// Выравнивание row: OLED_T (верх), OLED_C (центр), OLED_B (низ),   OLED_N (текущий Y)

void print(str, col, row);                // Вывод текста (char*, const char*, String, F("...") из Flash) или char

void print(doubleVal, col, row, dec);     // Вывод дробных чисел (dec - знаков после запятой, 0..9)
void printPadZero(val, width, col, row);  // Вывод числа с ведущими нулями до ширины width (напр. 007)

// ===== БЕГУЩАЯ СТРОКА =====
void printTicker(str, row, speedMs = 25, winX = 0, winW = 128); // Автопилот бегущей строки в окне
void resetTicker();                                             // Сброс позиции автопилота при смене текста
uint16_t printScroll(str, row, offsetX, winX = 0, winW = 128);  // Ручной попиксельный сдвиг

// ===== ГРАФИКА И БИТМАПЫ =====
void drawPixel(x, y, color = true);                             // Точка (в NO_BUFFER перезаписывает страницу)
bool getPixel(x, y);                                            // Чтение пикселя (только в OLED_BUFFER)
void drawHLine(x, y, len, dashLen = 1, gapLen = 0);             // Горизонтальная линия (сплошная или пунктир)
void drawVLine(x, y, len, dashLen = 1, gapLen = 0);             // Вертикальная линия (сплошная или пунктир)
void drawLine(x0, y0, x1, y1, color = true);                    // Произвольная линия (в NO_BUFFER только H/V)
void drawRect(x, y, w, h, dashLen = 1, gapLen = 0);             // Контур прямоугольника (сплошной или пунктир)
void fillRect(x, y, w, h, color = true);                        // Закрашенный прямоугольник
void drawCircle(x0, y0, r, fill = false, color = true);         // Окружность: контур или заливка (только в OLED_BUFFER)
void drawBitmap(col, row, bitmap, w, h, invert = false);        // Битмап из PROGMEM (формат vertical byte)

## Особенности безбуферного режима (`OLED_NO_BUFFER`)
Контроллеры SSD1306/SSD1309 по шине I2C принимают данные столбцами по **8 вертикальных пикселей (страницы `page 0..7`)** и не поддерживают чтение из памяти дисплея:
- В режиме `OLED_NO_BUFFER` вызов `drawHLine(x, y, len)` перезаписывает всю 8-пиксельную страницу `page = y / 8` на участке длиной `len` (остальные 7 пикселей по вертикали в этой полосе очищаются).
- **Не рисуйте две горизонтальные линии в пределах одной 8-пиксельной страницы** (`Y = 0..7`, `8..15`, `16..23`, `24..31`, `32..39`, `40..47`, `48..55`, `56..63`), иначе вторая линия сотрёт первую.
- Если нужно свободно накладывать фигуры друг на друга, рисовать круги, наклонные линии или печатать текст поверх рамок без затирания — используйте буферный режим `Danich_SSD130x_Fast<OLED_BUFFER>`.

## Таблица координат и переход между режимами

| Метод | Горизонталь (`X` / `col`) | Вертикаль в `OLED_NO_BUFFER` | Вертикаль в `OLED_BUFFER` |
| :--- | :--- | :--- | :--- |
| **`print(...)`**, **`printPadZero(...)`**, **`setCursor(...)`** | **Пиксели** (`0..127`) или `OLED_L`, `OLED_C`, `OLED_R`, `OLED_N` | **Страница `0..7`** (нижний край текста) или `OLED_T`, `OLED_C`, `OLED_B`, `OLED_N` | **Пиксели `0..63`** (верхний край текста) или `OLED_T`, `OLED_C`, `OLED_B`, `OLED_N` |
| **`drawBitmap(...)`** | **Пиксели** (`0..127`) или `OLED_L`, `OLED_C`, `OLED_R` | **Страница `0..7`** (верхний край картинки) | **Пиксели `0..63`** (верхний край картинки) |
| **`printScroll(...)`**, **`printTicker(...)`** | **Пиксели** (`0..127`) | **Страница `0..7`** (нижний край строки) | **Страница `0..7`** (нижний край строки) |
| **Вся графика** (`drawPixel`, `drawHLine`, `drawVLine`, `drawLine`, `drawRect`, `fillRect`, `drawCircle`) | **Пиксели** (`0..127`) | **Пиксели `0..63`** | **Пиксели `0..63`** |

### Двусторонний перенос скетчей без переписывания координат (`setPageCoord`)
По умолчанию в режиме `OLED_NO_BUFFER` используются страницы `0..7` (`setPageCoord(true)`), а в режиме `OLED_BUFFER` — точные пиксели `0..63` (`setPageCoord(false)`). Чтобы перенести скетч в другой режим без ручного пересчёта координат, достаточно добавить одну строку в `setup()`:
- **Перенос старого текстового скетча (`0..7`) в `OLED_BUFFER`:**
  1. Замените `Danich_SSD130x_Fast<> myOLED;` на `Danich_SSD130x_Fast<OLED_BUFFER> myOLED;`.
  2. Вызовите `myOLED.setPageCoord(true);` в `setup()` — все старые координаты страниц `0..7` будут автоматически пересчитываться в пиксели `Y` с учётом высоты выбранного шрифта и масштаба.
  3. Добавьте `myOLED.update();` в конце формирования кадра (или включите `myOLED.autoUpdate(true);` в `setup()`).
- **Перенос графического скетча (`0..63`) в `OLED_NO_BUFFER`:**
  1. Замените `Danich_SSD130x_Fast<OLED_BUFFER> myOLED;` на `Danich_SSD130x_Fast<> myOLED;`.
  2. Вызовите `myOLED.setPageCoord(false);` в `setup()` — пиксельные координаты `0..63` (включая `0..7`) будут автоматически приведены к ближайшим страницам.

## Пример
Полный демонстрационный скетч смотри в папке **`examples/Demo_All_Features`**!

```cpp

#include <microWire.h>
#include <Danich_SSD130x_Fast.h>

Danich_SSD130x_Fast<> myOLED(0x3C); // Безбуферный режим (0 байт ОЗУ)

void setup() {
  myOLED.begin(OLED_1309);
  Wire.setClock(600000L);

  myOLED.setFont(SmallFontRus);
  myOLED.print(F("Danich_SSD130x_Fast"), OLED_C, 0);
  myOLED.drawHLine(0, 10, 128);                 // Сплошной разделитель
  myOLED.drawRect(8, 16, 112, 24, 3, 2);        // Пунктирная рамка для бегущей строки
  myOLED.invText(true);
  myOLED.print(F(" RUN "), 8, 6);
  myOLED.invText(false);
  myOLED.print(F("Ver: "), 52, 6);
  myOLED.printPadZero(200, 3);
}
void loop() {
// Бегущая строка в окне X=10..117 (текст в восьмеричном коде CP866 для экономии Flash)
    myOLED.printTicker(
    F("\201\353\341\342\340\240\357 \241\245\247\241\343\344\245\340\255\240\357 \241\245\243\343\351\240\357 \341\342\340\256\252\240!"),
    3, 20, 10, 108);
    }
```
